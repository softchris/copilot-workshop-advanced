# Setup GitHub Copilot

To set up GitHub Copilot, follow these steps:

- Install the GitHub Copilot extension for your code editor. You can find the installation instructions for various editors in the [GitHub Copilot documentation](https://docs.github.com/en/copilot/managing-copilot/configure-personal-settings/installing-the-github-copilot-extension-in-your-environment). 
- Enable GitHub Copilot in your code editor. This is usually done by signing in with your GitHub account and enabling the extension in the editor settings. You might also need to enable GitHub Copilot via your GitHub account settings.
